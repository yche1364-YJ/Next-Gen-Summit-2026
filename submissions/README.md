# Submissions

Each accepted game has its own folder here, created automatically when a teacher approves a submission:

```
submissions/
  007-super-bouncy-adventure/
    game.zip     ← the team's project (Download Project Source)
    info.json    ← title, team, description, controls, scene
```

Students: don't add files here directly — use the **[upload page](https://yche1364-yj.github.io/Next-Gen-Summit-2026/upload.html)** ([guide](../docs/submit-guide.md)).
