# How to submit your game 🎮

When your team's game is finished, you'll submit it here so it appears in the **[Game Gallery](https://yche1364-yj.github.io/Next-Gen-Summit-2026/)** — a website where everyone can play every team's game in the browser. On presentation day, we'll play the games straight from the gallery.

**Only one person per team submits.** The whole process takes about 10 minutes.

| Step | What you do | Time |
|---|---|---|
| [1. Create a GitHub account](#step-1-create-a-github-account) | One teammate creates a free account (skip if you already have one) | 5 min |
| [2. Download your game](#step-2-download-your-game-as-a-zip) | Save your project as a ZIP file from the Godot web editor | 1 min |
| [3. Fill in the submission form](#step-3-fill-in-the-submission-form) | Upload the ZIP with your game's name and description | 3 min |
| [4. Wait for approval](#step-4-wait-for-approval) | Your teacher checks it and publishes it | — |

---

## Step 1: Create a GitHub account

GitHub is a website where people share code and projects. You need an account to submit.

> **You must be 13 or older to create a GitHub account.** If no one on your team can create one, skip to [No GitHub account?](#no-github-account) at the bottom of this page.

1. Go to **https://github.com/signup**.
2. Enter your **email address**. Use an email you can open right now — GitHub will send you a code.
3. Create a **password**.
4. Choose a **username**.
   - ⚠️ Your username is **public**. Don't use your full real name. Something like `alex-codes-2026` is great.
5. Follow the rest of the prompts. GitHub may ask you to solve a short puzzle to prove you're not a robot.
6. Open your email, find the message from GitHub, and **enter the code** (or click the link) to verify your email address.
7. If GitHub asks you some questions about how you'll use it, you can skip them. Choose the **Free** plan if asked.

✅ You're done when you can see the GitHub home page and you're signed in (your picture appears in the top-right corner).

> **Tip:** create your account **before** the last class, in case the email takes a while to arrive.

## Step 2: Download your game as a ZIP

1. Open your project in the **Godot web editor** (https://editor.godotengine.org/releases/latest/).
2. **Test it one last time:** press **F5**. What you see is what everyone will play in the gallery.
   - If your game is in a different scene (for example a new scene called `my_level.tscn`), remember that scene's name — you'll need it in Step 3.
3. Stop the game and go back to the **Editor** tab.
4. Open the **Project** menu → **Tools** → **Download Project Source**.
5. A ZIP file is saved to your computer, usually in your **Downloads** folder.

⚠️ **Don't unzip it and don't change anything inside it.** Upload the ZIP exactly as it is. It must be smaller than **25 MB**.

---

## Step 3: Fill in the submission form

1. Make sure you're signed in to GitHub.
2. Open the form: 👉 **[Submit our game](https://github.com/yche1364-YJ/Next-Gen-Summit-2026/issues/new?template=submit-game.yml)**
   *(Or go to the repository → **Issues** tab → **New issue** → **🎮 Submit our game** → **Get started**.)*
3. Fill in each box:

   | Box | What to write | Example |
   |---|---|---|
   | **Title** (at the top) | `[Game]` followed by your game's name | `[Game] Super Bouncy Adventure` |
   | **Game title** | Your game's name | `Super Bouncy Adventure` |
   | **Team name** | Your team's name | `The Space Hoppers` |
   | **Team members** | **First names or nicknames only** | `Alex, Sam` |
   | **About the game** | 1–3 sentences: the goal and what you changed | `Collect all the coins! We added giant trampolines and made gravity lower.` |
   | **Controls** | How to play | `Player One: ← → to move, ↑ to jump` |
   | **Scene to play** | Leave `main.tscn` unless your game is in another scene | `main.tscn` |
   | **Game ZIP file** | **Drag your ZIP file into this box** | — |

4. **Uploading the ZIP:** drag the ZIP file from your Downloads folder into the **Game ZIP file** box. Wait a few seconds until you see a link like:
   ```
   [my-game.zip](https://github.com/user-attachments/files/12345678/my-game.zip)
   ```
   Don't submit until the link appears — that means the upload is finished.
   *(Can't drag? Click the box, then click the 📎 paperclip / "Paste, drop, or click to add files" below it to choose the file.)*
5. Tick all three boxes in the **Checklist**.
6. Click **Create** (or **Submit new issue**).

🎉 That's it! Your submission now appears in the **Issues** list with the `submission` label.

---

## Step 4: Wait for approval

Your teacher will check your submission. GitHub emails you when there's a reply, or you can check your issue page.

- ✅ **Approved:** you'll get a comment with a link to your game. After **5–10 minutes**, your game is playable in the [Game Gallery](https://yche1364-yj.github.io/Next-Gen-Summit-2026/). Your issue gets the `published` label.
- ⚠️ **Needs a fix:** you'll get a comment explaining the problem and the `needs-fix` label. Fix it (see below), then reply to the comment so your teacher knows.

### How to fix or update your submission

1. Open your issue (Issues tab → click your game).
2. Click the **`···`** button at the top-right of your first message → **Edit**.
3. To replace the game: delete the old ZIP link in the **Game ZIP file** section and drag in the new ZIP. Wait for the new link to appear.
4. Fix any other text, then click **Save** (or **Update comment**).
5. Add a comment like *"Updated!"* so your teacher can approve it again.

**Don't open a new issue** for the same game — always edit your existing one.

---

## Presentation day

Open the **[Game Gallery](https://yche1364-yj.github.io/Next-Gen-Summit-2026/)**, find your game, and click **▶ Play**. Click once on the game so it receives the keyboard, then press any key to start. The **← All games** button in the bottom-right corner takes you back to the gallery.

## FAQ

**Our game works in the editor but not in the gallery.**
Make sure **Scene to play** is the scene you tested. Then [edit your issue](#how-to-fix-or-update-your-submission) and tell your teacher.

**I can't find my ZIP file.**
Look in your **Downloads** folder. The file name usually ends with `.zip`. If it's not there, repeat [Step 2](#step-2-download-your-game-as-a-zip).

**The upload says the file is too big.**
GitHub only accepts files up to 25 MB. Remove big pictures or sounds you added but don't use, download the project again, and try again.

**I didn't get the email code from GitHub.**
Check your spam folder, wait a few minutes, or ask GitHub to send it again. Make sure you typed your email address correctly.

**Can both teammates submit?**
No — one submission per team. The other teammate can follow along or add a comment on the issue.

**Is my submission public?**
Yes. Everyone can see the issue and play the game. That's why we only use first names or nicknames.

### No GitHub account?

If no one on your team can create a GitHub account (for example because you're under 13), **give your ZIP file to your teacher** together with your game title, team name, first names, a short description and the controls. Your teacher will submit it for you.
